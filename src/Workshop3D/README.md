## 🚀 QUICK START (5 MINUTES)

### Step 1: Import Component
1. Go to "📥 Import" tab
2. Enter file path or create primitive
3. Click "Import STEP" or "Create Component"

### Step 2: View in Library
1. Go to "📚 Library" tab
2. Search for component
3. Click "Select"

### Step 3: Place in Scene
1. Go to "📍 Placement" tab
2. Set position, rotation, scale
3. Click "Add to Scene"

### Step 4: Visualize
1. Go to "🎨 Visualization" tab
2. Choose visualization mode
3. View results

## ❓ COMMON QUESTIONS

**Q: How do I import a component?**
A: Go to Import tab, enter file path, click Import STEP

**Q: How do I add component to scene?**
A: Select in Library tab, go to Placement tab, click Add to Scene

**Q: What file formats are supported?**
A: STEP (.step, .stp) and GEO (.geo)

**Q: Can I create primitives?**
A: Yes, in Import tab - Box, Cylinder, Sphere, Cone

**Q: How do I visualize stress?**
A: Go to Visualization tab, select "Stress" mode

**Q: Can I search components?**
A: Yes, use search box in Library tab

**Q: How do I adjust component position?**
A: Go to Placement tab, set X, Y, Z coordinates

**Q: What's auto-placement?**
A: Automatically positions components to avoid overlap
