## HOW TO USE

### Step 1: View Library Weights
1. Click "📚 Library" tab
2. See all components with weights
3. Sort by weight if needed

### Step 2: Check Scene Weights
1. Add components to 3D scene
2. Click "🎬 Scene" tab
3. View total scene weight

### Step 3: Analyze Statistics
1. Click "📊 Statistics" tab
2. Review weight analysis
3. Check distribution

### Step 4: Export Data
1. Click "💾 Export" tab
2. Enter file path
3. Click "Export" button
4. Open CSV in Excel

## TABLE COLUMNS

| Column | Description |
|--------|-------------|
| Component Name | Name of component |
| Weight (kg) | Weight in kilograms |
| Percentage | % of total weight |

## SORTING OPTIONS

- **Name** - Alphabetical order
- **Weight (Low→High)** - Lightest first
- **Weight (High→Low)** - Heaviest first

---

## FILTERING

**Show Only Heavy Components:**
- Enable checkbox
- Set threshold (e.g., 10 kg)
- Only components above threshold shown
