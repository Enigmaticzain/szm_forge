## SETTINGS OVERVIEW

### Auto-Save
- **Default:** ON
- **Purpose:** Automatically save components when imported
- **Use:** Quick workflow without manual saves

### Snap to Grid
- **Default:** OFF
- **Purpose:** Align components to grid
- **Use:** Organized, precise placement

### Grid Size
- **Default:** 0.1 units
- **Range:** 0.01 to 1.0
- **Purpose:** Control grid spacing
- **Use:** Fine-tune alignment

### Default Material
- **Default:** Steel
- **Options:** Steel, Aluminum, Titanium, Composite
- **Purpose:** Material for new primitives
- **Use:** Consistent material properties

### Show Component Info
- **Default:** ON
- **Purpose:** Display material and mass
- **Use:** Quick reference

### Physics Preview
- **Default:** OFF
- **Purpose:** Real-time physics simulation
- **Use:** Preview behavior

## HOW TO USE

### Step 1: Open Settings Tab
1. Click "⚙️ Settings" tab

### Step 2: Configure Options
1. Enable/disable Auto-Save
2. Enable/disable Snap to Grid
3. Adjust Grid Size if needed
4. Select Default Material
5. Toggle Display options

### Step 3: Apply Settings
- Settings apply immediately
- Affect all new components
- Saved automatically

### Step 4: Reset if Needed
- Click "Reset to Defaults"
- Restores all original settings
